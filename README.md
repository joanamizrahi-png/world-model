# CS399 World Model Research

Research repo for running and extending [InSpatio-WorldFM](https://github.com/joanamizrahi-png/worldfm), a real-time generative frame model for spatial intelligence.

## Structure

- `notebooks/` — Colab notebooks for running experiments
- `experiments/` — logs, configs, and results from runs
- `notes/` — research notes and paper summaries

## Related repos

- My fork of InSpatio-WorldFM: https://github.com/joanamizrahi-png/worldfm

## Setup

See `notebooks/01_run_demo.ipynb` to run the InSpatio demo on a GPU (Colab or cloud).
